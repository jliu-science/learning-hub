# Dora revision

Interactive Year 8 science and maths revision, built with HTML, CSS and JavaScript.

Website: https://jliu-science.github.io/dora-revision/

Open `index.html` locally, or use the website above after deployment. Progress is stored in the current browser and is not synced between devices.

## Publish updates

From this folder, review and commit the changed website files, then run `git push origin main`. GitHub Pages publishes from the root of the `main` branch.

This is a personal revision resource. Educational content and answer accuracy have not been independently reviewed. The physics topic is not yet available.
